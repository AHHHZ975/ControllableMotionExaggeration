# Controllable Exaggeration for Generative Motion Models

Project webpage for **“Controllable Exaggeration for Generative Motion Models via Training-Time Adaptation and Inference-Time Guidance.”**

The manuscript PDF is intentionally not included in this repository before its public release.

Once GitHub Pages is enabled, the webpage will be available at:

https://ahhhz975.github.io/ControllableMotionExaggeration/

## Adding the supplemental video

After uploading the supplemental video to YouTube, open `index.html` and replace:

```html
data-youtube-id="YOUR_YOUTUBE_VIDEO_ID"
```

with the video ID from the YouTube URL. For example, for `https://www.youtube.com/watch?v=abc123`, use:

```html
data-youtube-id="abc123"
```
